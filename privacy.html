Privacy Policy

Last updated: 7 October 2026

Who uses this app

RAB AGENT is a private application used only by its owner. It is not distributed to the public.

Google user data we access

With the owner's permission (Google Drive scope), the app:

  • reads one template spreadsheet in the owner's Google Drive;
  • creates or updates Excel (.xlsx) files in one Drive folder chosen by the owner;
  • lists the names of files in that folder, to find a file to revise.

The app does not read other files, emails, contacts, or any other Google data.

How the data is used and stored

File contents are processed only to fill in quantities requested by the owner. The Google authorization token is stored on the owner's own computer or server and is not shared. The app does not keep a separate database of Google user data.

Sharing

We do not sell, rent, or share Google user data with third parties, and we do not use it for advertising. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke access at any time at myaccount.google.com/permissions and can delete the token file and any generated files at any time.
