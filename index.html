RAB AGENT

A personal assistant that prepares water-connection cost estimates (RAB) as Excel files.

What it does

RAB AGENT is a private Telegram bot used by one person. When the owner sends a message such as "Cs2, Elbow 3, Pipa 20m", the app reads a template spreadsheet from the owner's own Google Drive, fills in the requested quantities, and saves the result as a new Excel file in a folder chosen by the owner.

It is not offered to the public and has no other users.

Google Drive access

The app uses the Google Drive permission only to read one template file and to create or update Excel files in one folder of the owner's Drive. See the Privacy Policy for details.

Tentang aplikasi (Indonesia)

RAB AGENT adalah bot Telegram pribadi untuk menyusun Rencana Anggaran Biaya (RAB) sambungan air dalam bentuk file Excel. Aplikasi hanya dipakai oleh pemiliknya dan mengakses Google Drive pemiliknya sendiri untuk membaca file template dan menyimpan hasilnya. Lihat Kebijakan Privasi.
